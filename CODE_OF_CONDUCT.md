# Code of conduct

We want participation in Agent OS to be safe, respectful, and useful.

Be considerate, critique ideas and code rather than people, respect privacy, and avoid harassment,
discrimination, threats, sexualized attention, doxxing, or deliberate disruption. Maintainers may
edit or remove contributions and restrict participation when behavior undermines the community or
its safety.

Report conduct concerns privately through the maintainer contact shown on the Frantz Studio GitHub
profile. Do not include unrelated private data. Reports will be handled as confidentially as
practical, with conflicts of interest disclosed.
