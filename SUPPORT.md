# Support

Agent OS `0.1.x` is a best-effort public alpha.

- Use GitHub Issues for reproducible bugs and bounded feature requests.
- Use GitHub Discussions, when enabled, for usage questions and design discussion.
- Use private vulnerability reporting for security issues.
- Upstream NOOA, Omnigent, Prime Agent, OpenCode, model-provider, and Ollama defects should be
  reproduced against the upstream project before being filed here.

There is no SLA, hosted service, backward-compatibility guarantee, or support for unattended
production deployment. Include `agent-os --version`, `agent-os doctor` output with secrets removed,
the operating system, Python version, harness, provider, and a minimal reproduction.
